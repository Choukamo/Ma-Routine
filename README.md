# Ma Routine

Appli mobile (PWA) : planning beauté (jour / semaine / mois), objectifs nutrition et « manger léger le soir », programme sport post-partum progressif (rééducation du périnée → reprise → renforcement), liste de tâches et pense-bête.

Les données restent dans le navigateur du téléphone (localStorage), avec sauvegarde / restauration en fichier JSON.

```
npm install
npm run dev
npm run build
```
